# Bohol Beach Club — Private Redesign Concept

Private concept website built from the Resort Intelligence research package for Bohol Beach Club.

## Purpose

This repository is an isolated redesign prototype. It does not replace or modify the resort's live website and it does not modify the Velamar project.

## Research basis

- Source website: `https://www.boholbeachclub.com.ph/`
- Fresh bounded crawl: 12 pages, 115 assets, 120 sitemap URLs
- Opportunity score: 92
- Accommodation evidence: 80 Deluxe Rooms + 8 Beachview Suites
- Dining evidence: Agotata coffee shop, 6:00 AM–10:00 PM
- Experience evidence: Club Aquasports, diving, island hopping, tours and transportation
- Events evidence: wedding and corporate function facilities
- Address evidence: Bo. Bolod, Island of Panglao, Bohol, Philippines 6340
- Reservations: `reservations@boholbeachclub.com.ph`

The normalized research export is preserved under `research/export/`.

## Local development

npm install
npm run dev
